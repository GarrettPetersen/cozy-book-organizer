# Cozy Book Organizer

Playable browser prototype for a cozy used-bookstore organizing and management game.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create the production site in `dist/`.

## Deployment

Cloudflare Pages builds and deploys the `master` branch automatically with:

- Build command: `npm run build`
- Output directory: `dist`
- Production URL: <https://cozy-book-organizer.pages.dev>
